# 음악 일기 (Music Diary)

오늘의 기분을 고르면 어울리는 곡을 추천해주고, 플레이리스트로 모아 듣고, 들은 곡과 함께
하루를 기록하는 모바일 웹 음악 앱입니다. 팀 **Clova**의 프로젝트입니다.

**배포 링크**: https://hkpiuuyk.github.io/project/

## 주요 기능

- **홈**: 기분(차분함/설렘/위로/집중/그리움)을 고르면 배경이 그 기분 색으로 물들고,
  오늘의 추천곡과 실제 재생 기록 기반 최근 재생 목록을 보여줍니다. 고른 기분은 다음 접속 때도
  그대로 유지됩니다.
- **라이브러리**: MP3/WAV 파일을 여러 개 한 번에 업로드해 곡을 추가합니다(제목/아티스트/커버
  자동 인식). 플레이리스트를 만들어 곡을 검색해 담고, 순서를 드래그로 바꾸고, 스와이프나
  버튼으로 뺄 수 있습니다. 전체/좋아요/최근재생 탭으로 목록을 걸러 볼 수 있습니다.
- **탐색**: 곡 제목이나 아티스트로 검색합니다.
- **일기**: 함께 들은 곡을 직접 골라, 오늘의 기분과 짧은 글을 남깁니다. 저장한 일기는 마이
  탭에서 다시 볼 수 있습니다.
- **미니 플레이어 / 전체 플레이어**: 화면 하단에서 재생과 다음 곡을 조작합니다. 전체
  플레이어에서는 셔플과 한 곡 반복을 켤 수 있고, 다음 곡 목록은 드래그로 순서를 바꾸거나
  스와이프로 지울 수 있습니다. 헤더를 위로 끌어 올리면 목록이 펼쳐지고, 아래로 끌어 내리면
  접히거나 닫힙니다. 마지막으로 듣던 곡과 재생 위치, 재생목록은 브라우저를 껐다 켜도
  그대로 이어집니다.
- **마이**: 작성한 일기와 플레이리스트 개수를 보여주고, 재생 설정(자동 재생 등)과 이용약관,
  크레딧을 확인할 수 있습니다. 저장된 데이터를 한 번에 지우는 전체 데이터 초기화 기능도
  있습니다.
- **반응형 레이아웃**: 모바일부터 태블릿까지 대응하며, PC 등 더 큰 화면에서는 레이아웃이 깨질
  수 있다는 안내를 보여줍니다.

## 기술 스택

- React 19 + TypeScript
- Vite 8
- Oxlint
- 상태 관리는 `useState`만 사용합니다(별도 라이브러리 없음). 텍스트 데이터는 `localStorage`,
  업로드한 오디오 파일과 커버 이미지는 `IndexedDB`에 저장합니다.

## 시작하기

```bash
npm install
npm run dev      # 개발 서버, http://localhost:5173
npm run build    # 프로덕션 빌드 (tsc -b && vite build)
npm run lint     # oxlint
npm run preview  # 빌드 결과 미리보기
```
